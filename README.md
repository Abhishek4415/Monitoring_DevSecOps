
# Lab 3: Monitoring, Logging & DevSecOps

## Overview

This lab focuses on designing and implementing an automated, observable, and secure infrastructure workflow using DevOps and DevSecOps tools.

The lab covers infrastructure provisioning, configuration management, monitoring, centralized logging, security scanning, feature flags, load testing, and automated browser testing.

## Objectives

- Automate infrastructure provisioning using Terraform.
- Configure infrastructure using Ansible.
- Monitor system metrics using Prometheus.
- Visualize monitoring data using Grafana.
- Implement centralized logging using the ELK Stack.
- Integrate security scanning into the DevOps pipeline.
- Implement feature flags and load testing.
- Perform automated browser testing using Selenium.

## Tools & Technologies

- Terraform
- Ansible
- Prometheus
- Grafana
- Elasticsearch
- Logstash
- Kibana
- Selenium
- Git & GitHub

## Experiments

### 1. Infrastructure Provisioning
Automate infrastructure creation and management using Terraform.

### 2. Configuration Management
Configure systems and services using Ansible playbooks.

### 3. Monitoring
Collect and visualize system metrics using Prometheus and Grafana.

### 4. Centralized Logging
Collect, process, and analyze application and system logs using the ELK Stack.

### 5. Security Scanning
Integrate security and quality checks into the DevOps pipeline.

### 6. Feature Flags
Control application features without requiring a new deployment.

### 7. Load Testing
Evaluate application performance under different levels of traffic.

### 8. Automated Browser Testing
Automate browser-based application testing using Selenium.
